# Learning Resources


## Foxglove Documentation

Foxglove is a visualization and debugging tool for robotics. It is super usefull and cool to boot. If you are a learn by documentation kind of person I recommend the [Foxglove Documentation](https://docs.foxglove.dev/).

I found those slightly helpful but I myself am a visual learner and if you are too, I would recommend this [beginner video series](https://foxglove.dev/blog/get-started-with-foxglove-videos-for-new-users). It really has all you need to know for what we are doing.

## VS Code Dev Containers

https://code.visualstudio.com/docs/devcontainers/containers

Since the project is developed inside containers, understanding Dev Containers is useful.

This documentation explains how VS Code communicates with Docker containers and how development environments can be shared between team members. Reading through it helped me better understand how the project's setup process works behind the scenes.

---

## Docker Documentation

https://docs.docker.com/

Docker is one of the most important tools used in the project because the entire development environment depends on it.

While I did not read extensive Docker documentation during onboarding, I frequently used it when troubleshooting container issues and learning how the project's environment was organized. And there was a LOT of container troubleshooting.

---

## Additional Notes

One thing I learned during onboarding is that it is easy to focus entirely on getting the software running and forget to understand what the tools are actually doing. There are a lot of smart people in the room with you, so ask your section head or even peers for help or explanation if necessary. We are all learning together!

Spending time with the ROS2 tutorials and Foxglove made the rest of the project much easier to understand. Even though these resources are not specific to this repository, they provide the foundation needed to work effectively with the project.
