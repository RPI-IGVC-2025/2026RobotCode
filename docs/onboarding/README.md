# New Member Onboarding Guide

This guide is for learning the ropes of the robot, and not for setting up the containers or code as that is documented in install.md.

This folder is about the process I followed, the things I was told to learn about, and several resources that were helpful for understanding the robot.

## Contents

### Getting Started Guide
A walkthrough of the setup process, including Docker, VS Code Dev Containers, ROS2, and Foxglove.

### Learning Resources
Some of the resources I use to learn the tools above, as well as a short explanation of why each one was useful.

## Who This Is For

This guide is intended for new team members who are coming in with minimal experience or have to learn some new tools
